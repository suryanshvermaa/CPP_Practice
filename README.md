# DSA Questions (C/C++) ✨

Simple repository of data structures & algorithms questions and solutions. Nothing fancy — just practice code. 💪

---

## Folders 🗂️
- 🔎 `BS/` — Binary Search problems
- 🌳 `BST/` — Binary Search Trees
- 🌴 `binary_trees/` — Binary Trees (traversals, diameter, etc.)
- 🧵 `strings/` — String utilities and tricks
- 🔍 `searching/` — Basic searching
- 🔀 `sorting/` — Sorting algorithms
- 🧺 `Stack-Queue/` — Stack/Queue implementations
- 🧠 `dp_on_string/` — DP on strings
- 🧩 `dp2/` — More DP problems
- 🗺️ `graph2/` — Graph algorithms (Dijkstra, Prim, Kruskal, etc.)

> Most files are small, self-contained programs with a `main()` and a hard-coded example.

---

## Run a file ▶️
Create a build folder once and compile any file you want:

```bash
mkdir -p build
g++ -std=c++17 -O2 BS/1_BS.cpp -o build/bs && ./build/bs
```

For `.c` files (e.g., C bubble sort):

```bash
gcc -O2 sorting/bubble_sort.c -o build/bubble_c && ./build/bubble_c
```

Note: Many files use `#include <bits/stdc++.h>` (works with GCC).
